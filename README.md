### 🧠 核心理念

我厌倦了满屏的广告和复杂的配置，也反感技术被无底线地榨取。这个项目证明了：**一个单文件 HTML，就能装下一个有灵魂的 AI 世界。**

它不是简单的 API 调用展示，而是一个集成了**逻辑大脑（LLM）**、**物理引擎（Audio）**与**视觉画板（SVG）**的三位一体交互实验。

---

### ✨ 核心特性

#### 🔬 硬核音频：物理建模合成器
这是本项目最引以为傲的部分。它**不是**在播放死板的 MP3 采样，而是在浏览器里利用 Web Audio API 实时“算”出声音。
- **真实物理模拟**：代码底层模拟了击弦 (`hammer`)、拉弦 (`bowed`)、铜管 (`brass`)、气鸣 (`wind`) 等真实乐器的发声特性。
- **丰富音色库**：内置 14 大类乐器（钢琴、弦乐、吉他、贝斯、合成器等），每一类都有独立的波形、滤波和包络设置。
- **专业级算法**：包含基于代码生成的卷积混响 (`getReverb`) 和动态力度响应，让 AI 生成的音乐充满情感。

#### 🎨 实时绘图：SVG 矢量图形引擎
AI 能够理解几何逻辑，直接在对话框中生成可缩放的矢量图形。
- **所见即所得**：支持绘制爱心、星星、房子、云朵、彩虹、火箭等数十种图形。
- **组合艺术**：AI 可以通过代码组合出复杂的场景（例如“一个带皇冠的笑脸”或“飞向太空的火箭”）。

#### 🪶 极致轻量：单文件架构
- **零依赖运行**：不需要 Node.js，不需要 Python，不需要数据库。下载 `index.html`，双击即可在任何现代浏览器中运行。
- **强约束规则**：通过精心设计的系统提示词 (`AUTO_RULES`)，驯服了大模型的输出格式，使其能精准执行画图与作曲指令。

### 🚀 快速开始

1.  **获取文件**：下载本仓库中的 `index.html` 文件。
2.  **本地运行**：直接双击文件在浏览器（推荐 Chrome / Edge / Firefox）中打开。
3.  **配置模型**：点击右上角设置图标，填入你常用的 LLM API Key。
4.  **开始创作**：尝试输入以下指令体验它的魔力：
    - `画一个红色的爱心，然后用钢琴弹一首小星星。`
    - `用铜管乐器吹一段胜利的旋律，并画一面飘扬的旗帜。`
